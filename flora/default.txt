# The shared flora for the outdoor classic zones (assets/zone_flora.h, docs/graphics.md "Zone flora"): Hailstone's own.
# A zone without a file of its own takes these when the server calls it outdoor. Grass grows on level, open ground
# where the texel under it is green, so sand, snow, rock, roads, water and lava stay bare; each plant takes the
# ground's colour. The shapes and pictures are the player's own commonlands.eqg's, read from the game folder.
# The first matching line wins.
donor commonlands.eqg
max_slope 45
scale 0.9 1.3
