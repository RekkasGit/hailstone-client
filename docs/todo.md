## Memory

- [x] **A zone's textures and uploads** (docs/graphics.md).
  - A fully opaque power-of-two image's mip chain is built by the GPU (on an sRGB view, in linear light, as the CPU chain) instead of on the CPU.
  - The zone's uploads are staged to the card in pieces rather than in one lot.
  - The PR author's measurement, on dragonscale in the zone viewer, before opaque images of odd sizes went back to the CPU chain: the peak commit fell from 1,468 MB to 1,353 MB and the peak working set from 740 MB to 625 MB.
  - In a live session in a small classic zone (Direwind Cliffs) the peak did not move.
  - Not measured again since.
- [ ] **The character archives: the largest single term in the client's memory.**
  - The 135 global character archives cost about 926 MB.
  - The client's own log: `zone load: start: 345 MB`, then `character archives: 135 global (with Luclin models) in 1439 ms`, then `zone load: start: 1271 MB`.
  - Archives in the game folder are now mapped read-only instead of held as a heap copy, so only the index is private and the bytes live in the file cache. Overlay archives are still read into the heap (docs/hardening.md "Mapped game archives").
  - Character WLDs keep a compact resource index and decode on first use.
  - A decoded WLD whose last reader is done stays in a retained set of 128 MiB (least recently released out first), so that model after model does not decode it again.
  - The archive-bytes / parsed split of that 926 MB is still unmeasured.
  - Next:
    - measure fresh and repeated-zone memory and decode counts with the retained set, and pick its budget from that;
    - compare Windows private commit with resident checkpoints and model animation/geometry subtotals after shared/compacted animation keys;
    - attribute name tables, parsed EQG source data and allocator retention before further cache policies.
- [ ] **The base cost.**
  - About 492 MB before any zone is loaded: the sound library's index over the 17 `snd*.pfs` at 119 MB, the spell particle definitions, the sky colour maps, the hero's forge tags, the fonts.
  - About 200 MB of shadow maps at the defaults (six 2048² cascades and the point-light cubes).
  - Which of these is how much has not been measured one by one; the same goes for the transient above the end-of-zone figure.
- [ ] An allocator of the client's own (mimalloc or jemalloc): the client uses the system allocator throughout, so the memory it asks for is not the memory it holds.
